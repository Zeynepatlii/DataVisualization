# Data Visualization

Bu repository, Veri Görselleştirme dersi kapsamında kullanılan
ders materyallerini, R/Python kodlarını, veri setlerini ve
uygulamaları içermektedir.

## Ders İçeriği

- Temel grafikler
- Görsel kodlama
- Çok değişkenli görselleştirme
- Etkileşimli grafikler
- Dashboard
- Veri hikâyeleştirme

## Kullanılan Araçlar

- R / ggplot2
- Python
- Shiny
- Plotly

## Ders Materyalleri

Her haftaya ait kodlar, veri setleri ve uygulamalar ilgili
klasörlerde paylaşılacaktır.
